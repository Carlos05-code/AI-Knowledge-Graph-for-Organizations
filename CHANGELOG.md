# Changelog

## [1.0.0] - 2026-07-31

### Added
- Initial release
- Universal Connectors (Google Drive, Slack, GitHub, Notion, Confluence, Jira, etc.)
- Document Processing Pipeline (OCR, parsing, chunking, embedding)
- AI Chat with RAG and citation extraction
- Enterprise Search (keyword, semantic, hybrid)
- Automatic Knowledge Graph extraction (Neo4j)
- Knowledge Graph Explorer with interactive visualization
- Expertise Discovery engine
- Meeting Intelligence (transcription, summaries, action items)
- Policy Search with version tracking
- Knowledge Gap Detection
- Recommendations engine
- Notifications system
- Authentication via Keycloak with JWT + Refresh Tokens
- RBAC and ABAC authorization
- Audit logging
- Full-text search via OpenSearch
- Vector search via Qdrant
- Caching via Redis
- Message queuing via RabbitMQ
- Object storage via MinIO
- Docker Compose and Kubernetes deployment configs
- Comprehensive API documentation (OpenAPI)
- Monitoring with Prometheus + Grafana + Loki
- CI/CD with GitHub Actions
